## Supabase MCP is available (project default)

Assume this project is connected to **Supabase via MCP**.

- Prefer **Supabase MCP** tools/workflows for anything involving Supabase (DB queries, auth, storage, migrations, RLS policy inspection, etc.).
- If Supabase MCP tools are not available in the current session (missing server, not authenticated, or disconnected), ask to **reconnect/authenticate Supabase MCP** and proceed via MCP once available.
- Do not recommend manual Supabase CLI / dashboard steps as the first option when MCP can do it.
